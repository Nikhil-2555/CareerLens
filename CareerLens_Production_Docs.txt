1.6 Non-Functional Requirements
Security
All API routes require Authorization: Bearer <accessToken> except /auth/*
JWT secrets stored in environment variables only; never committed to source control
Refresh tokens stored as HTTP-only, Secure, SameSite=Strict cookies
Uploaded files scanned with file-type package to validate MIME; stored in /tmp, never served directly
Rate limiting: 60 req/min per IP on all routes; 10 req/min per user on /api/ai/* routes
Helmet.js sets all recommended security headers
CORS restricted to frontend origin via environment variable

Performance
First Contentful Paint < 1.5s (React code-split by route)
AI endpoint P95 < 10s; streaming response used to reduce perceived latency
MongoDB indexes on: users.googleId, applications.userId, applications.status
File upload uses multipart streaming (Multer); max 5 MB enforced at middleware level

Accessibility
WCAG 2.1 AA compliance for all core flows
Kanban board keyboard-navigable (arrow keys, Enter to expand)
All form inputs have visible labels and ARIA attributes
Color contrast ratio >= 4.5:1 for all text

Compliance
GDPR: users can request data export and account deletion via settings page
Uploaded files deleted from server after text extraction (not persisted on disk)
OpenAI API calls: no PII sent beyond resume text; user data not used for model training (Enterprise API)

2. System Architecture Overview
2.1 High-Level Architecture
CareerLens follows a three-tier architecture: a React SPA served from a CDN, a stateless Node/Express API on a container host, and a managed MongoDB Atlas cluster. The AI layer is an external dependency (OpenAI API) called exclusively from the server, never the client.

Client (React SPA on Vercel CDN) --> Express API (Railway / Render) --> MongoDB Atlas (M0 free / M10 production)
Express API --> OpenAI GPT-4o API (server-side only)
Express API --> Google OAuth 2.0 (passport-google-oauth20)

Request Flow: Resume Analysis
User uploads resume file via React dropzone (multipart/form-data)
Express Multer middleware validates file type and size
pdf-parse / mammoth extracts raw text from file
Auth middleware verifies JWT from Authorization header
Analysis controller builds structured prompt, calls OpenAI Chat Completions API
Response JSON (score, strengths, gaps) saved to MongoDB analyses collection
Response streamed back to client; React renders score card

3. API Design Guide
3.1 Base URL & Versioning

3.2 Authentication Flow
Google OAuth + JWT
Client navigates to GET /auth/google
Passport.js redirects to Google consent screen
Google redirects to GET /auth/google/callback with authorization code
Passport exchanges code for Google profile; upserts user in MongoDB
Server issues: accessToken (JWT, 15 min, in JSON body) + refreshToken (JWT, 7 days, HTTP-only cookie)
Client stores accessToken in memory (React context); sends as Authorization: Bearer <token>
On 401 response, client calls POST /auth/refresh; server validates refresh cookie, issues new pair
POST /auth/logout clears cookie and marks refresh token revoked in DB

Security note: never store accessToken in localStorage. Keep in memory only to prevent XSS token theft.

9.6 src/api/axios.js (Token Refresh Interceptor)
import axios from 'axios';

const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  withCredentials: true, // send refresh cookie automatically
});

let accessToken = null;
export const setAccessToken = (t) => { accessToken = t; };

api.interceptors.request.use((config) => {
  if (accessToken) config.headers.Authorization = `Bearer ${accessToken}`;
  return config;
});

api.interceptors.response.use(
  (res) => res,
  async (error) => {
    const original = error.config;
    if (error.response?.status === 401 && !original._retry) {
      original._retry = true;
      try {
        const { data } = await axios.post(
          `${import.meta.env.VITE_AUTH_URL}/refresh`,
          {}, { withCredentials: true }
        );
        setAccessToken(data.accessToken);
        original.headers.Authorization = `Bearer ${data.accessToken}`;
        return api(original);
      } catch {
        setAccessToken(null);
        window.location.href = '/';
      }
    }
    return Promise.reject(error);
  }
);

export default api;
